## 🚀 How to Use

1. Simple Download

If you just want one or two images, navigate to the folder of your choice, click on the image, and hit the Download button.

2. Clone the Entire Repo

To get the whole collection at once:

```bash
git clone --depth 1 git@github.com:CJTS15/wallpapers.git
```

 I recommend using --depth 1 to save time and bandwidth, as it only downloads the latest version of the files without the full history.
